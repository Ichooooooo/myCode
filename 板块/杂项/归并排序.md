# 归并排序

## 说明

如果用来排序其实是用不到的, 但可以用来做逆序对

## 思路

把数组不断切成两半，分别排好，再把两个有序数组合并。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;

int a[N], tmp[N];

void merge_sort(int l, int r) {
    if (l >= r) return; // 只有一个数，不用排序

    int mid = (l + r) / 2;

    merge_sort(l, mid);
    merge_sort(mid + 1, r);

    int i = l, j = mid + 1, k = l;

    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }

    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];

    for (int p = l; p <= r; p++) {
        a[p] = tmp[p];
    }
}

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) cin >> a[i];

    merge_sort(1, n);

    for (int i = 1; i <= n; i++) cout << a[i] << " ";

    return 0;
}
```
