# 基本概念

## 图论

### 基本概念
  
#### 图基本概念
- 重边 : 两点之间有多条边, 一般算作不同的边
- 路径 : 从一个点沿边走到另一个点。
- 环 : 能从某个点出发，又回到自己。
  
#### 有向图常见说法
- 有向图 : 可以分为连通图和不连通图, 意思是可以分为多个没有连通边的点集
- 强连通(SCC) : 有向图里，如果任意两个点 u, v 都满足 : u 能走到 v，v 也能走到 u, 那叫 **强连通**
` Tarjan 求 SCC`
- 强连通分量 SCC : 有向图中，互相能到达的一组点，叫 强连通分量, 例如 1 -> 2 -> 1
- DAG : 有向无环图, 1 -> 3 -> 4 `常见应用 : 拓扑排序, DAG 上 DP, 缩点建 DAG`

#### 无向图常见说法
- 连通图 : 任意两点都能互相到达
- 连通块 : 图分成的若干块
- 桥 : 删除这条边后连通块数量增加
- 割点 : 删除这个点后连通块数量增加

#### 树/森林基本概念
- 树 : 无向连通无环图
- 森林 : 一个无向图没有环，但不一定连通
- 树直径 : 树上最长简单路径
