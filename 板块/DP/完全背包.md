# 完全背包

## 场景
有 n 个物品，每个物品有：
- cost[i]：花费（重量）
- val[i]：价值
每件物品无限选择

你有一个容量为 m 的背包。

**目标：** : 选一些物品，使得 总 cost ≤ m，同时 总价值最大。

## 思路
1. 按照任意顺序dp每一件物品

2. dp按照[cost, m]正序遍历, 因为可以无限选

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, V;
    cin >> n >> V;

    vector<int> v(n + 1), w(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> v[i] >> w[i];
    }

    vector<long long> dp(V + 1, 0);

    for (int i = 1; i <= n; i++) {
        for (int j = v[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
        }
    }

    cout << dp[V] << '\n';
    return 0;
}
```
