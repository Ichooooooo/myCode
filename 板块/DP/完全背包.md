# 完全背包

## 基本场景
有 n 个物品，每个物品有：
- cost[i]：花费（重量）
- val[i]：价值
每件物品无限选择

你有一个容量为 m 的背包。

**目标：** : 选一些物品，使得 总 cost ≤ m，同时 总价值最大。

### 基本思路
1. 按照任意顺序dp每一件物品

2. dp按照[cost, m]正序遍历, 因为可以无限选

## 基本代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, V;
    cin >> n >> V;

    vector<int> v(n + 1), w(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> v[i] >> w[i];
    }

    vector<long long> dp(V + 1, 0);

    for (int i = 1; i <= n; i++) {
        for (int j = v[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
        }
    }

    cout << dp[V] << '\n';
    return 0;
}
```

## "至多" 和 "至少" 区别

### "至少"场景

有 n 个物品，每个物品有：
- cost[i]：花费（重量）
- val[i]：价值
每件物品无限选择

**目标：** : 选一些物品，使得 总 val >= m，同时 总花费最小。

### 区分

- 场景: 一般完全背包是至多情况下求max_val, 但是"至少"完全背包是至少情况下求min_cost

- 初始化: 一般情况初始化为0即可, "至少"需要初始化未到达情况
  
- 转移: 都是根据物品展开转移, 但是"至多"枚举体积的时候只用在背包体积内枚举; "至少"转移的时候, 明显如果目前 $val >= m$ 我们多选择一个物品不会更优秀, 所以我们枚举 $val$ 只转移到 $m + mxv$ 即可, 此时 $dp$ 含义是恰好 $val$ 的时候的最小 $cost$

- 另一种转移: 根据物品展开决策的时候, 我们能从前一个决策 (可能是上一个物品或者这个物品可能已经选了几个) val 转移过来, 同上, val从 (0, m), 这时候 $dp$ 含义为 至少 $val$ 的时候的 最小 $cost$, 取 $min(val + cost[i], m)
