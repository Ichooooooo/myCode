# 多重背包基础版

## 基本场景
每种物品有：

- 体积 $v_i$, 价值 $w_i$
- 每个数量上限 $s_i$
- 背包总容量 $V$ 	​

## 对比
 00 ./01 背包：每种只能选 0/1 个

完全背包：每种可以无限选

多重背包：每种最多选 𝑠𝑖 个

## 基本思路
1. 枚举物品
2. 01背包枚举体积
3. 枚举数量转化为01背包(注意复杂度)

## 对比版本

1. 转移从本层, 倒序枚举
```cpp
// 直接用本状态更新, 倒序防止本状态互相影响
for (int i = 1; i <= n; i++) {
        // 原地更新时，必须倒序，保证转移来源仍是“上一层”
    for (int j = V; j >= 0; j--) {
        for (int k = 1; k <= s[i] && k * v[i] <= j; k++) {
            dp[j] = max(dp[j], dp[j - k * v[i]] + k * w[i]);
        }
    }
}
```

2. 转移从上一层, 都可以
```cpp
// pre是前一个状态, 用于转移
for (int i = 1; i <= n; i++) {
    dp = pre;
    for (int j = 0; j <= V; j++) {
        for (int k = 1; k <= s[i] && k * v[i] <= j; k++) {
            dp[j] = max(dp[j], pre[j - k * v[i]] + k * w[i]);
        }
    }
    pre = dp;
}
```


## 基础代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, V;
    cin >> n >> V;

    vector<int> v(n + 1), w(n + 1), s(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> v[i] >> w[i] >> s[i];
    }

    vector<int> dp(V + 1, 0);

    for (int i = 1; i <= n; i++) {
        // 原地更新时，必须倒序，保证转移来源仍是“上一层”
        for (int j = V; j >= 0; j--) {
            for (int k = 1; k <= s[i] && k * v[i] <= j; k++) {
                dp[j] = max(dp[j], dp[j - k * v[i]] + k * w[i]);
            }
        }
    }

    cout << dp[V] << '\n';
    return 0;
}
```
