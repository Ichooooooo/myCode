# 树上dp

## 基本场景

- 父节点的状态明显从子节点转移过来, 有子树结构

## 基本过程

- 定根
- 设计转移状态
- DFS先算儿子
- 回溯时参与父节点dp转移

## 基本类型

- 子树统计
- 选点类型 (二维, 相邻有限制)
- 树形背包 (dp[i][j], i是子树根节点, j是选择的数量, 求最优解)
- 换根dp (不会)

## 基本代码

[树形背包](https://www.luogu.com.cn/problem/P1273)

### 题意

给定一棵无向树, 边有边权, 叶子节点有点权, 如果想获得叶子节点的点权, 需要支付从根节点到叶子节点的边权, 边权不需要重复支付
求不亏本的情况能得到的最多的叶子节点

### 思路

1. 决策路径: 这道题有明显的树状结构, 因为重复边权只算一次, 所以按照某个根节点下选取多少叶子节点决策

2. 状态要记录什么: dp[u][k] 表明在子树根节点 $u$ 下选择 $k$ 个叶子节点的最大价值 (这里价值是成本 - 叶子节点价值)

3. 最后一步: 树上背包, dp[u][k]从所有子树的最优解做背包转移而来, 但是注意和正常已知背包体积倒着转移不同, 我们树上转移从根节点往下递归, 从 $u$ 到不同的 $v$, 加法转移更方便, 从sz[u] -> sz[u] + sz[v]
$$
dp[u][k + t] = max (dp[u][k + t], dp[v][t] + dp[u][k] - cost);
$$

4. 转移方向: dp[u][k]决策按照子节点展开, 我们加法转移, 每次需要更小的值, 所以背包反向枚举, 子树方向无所谓

5. 初始化: dp[u][0] = 0, 其他设置成未定义INF

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAXN = 3005;

int N, M;

// g[u] 里存的是：u -> v，边权 cost
vector<pair<int,int>> g[MAXN];

// pay[u]：如果 u 是用户节点，它愿意支付的钱
int pay[MAXN];

// sz[u]：u 的整棵子树里，一共有多少个“用户叶子”
// 也就是：在 u 子树里最多能选多少个用户
int sz[MAXN];

// dp[u][k]：在 u 的子树里，恰好选 k 个用户时，最大净收益
// 净收益 = 用户付款总和 - 所有使用到的边费用
int dp[MAXN][MAXN];

void dfs(int u) {
    // 先把这一行都设成“负无穷”，表示这种状态暂时不可能达到
    for (int i = 0; i <= M; i++) dp[u][i] = -INF;

    // 选 0 个用户，收益一定是 0
    dp[u][0] = 0;

    // 如果 u 是叶子用户
    // 题目保证用户编号是 [N-M+1, N]
    if (u > N - M) {
        // 这个子树里只有它自己这 1 个用户
        sz[u] = 1;

        // 选 1 个用户，就是选它自己，获得它的付款
        dp[u][1] = pay[u];

        return;
    }

    // 如果 u 是中转站，初始时还没合并任何儿子
    sz[u] = 0;

    // 依次处理每个儿子 v
    for (auto [v, cost] : g[u]) {
        dfs(v);  // 先算出儿子子树的 dp

        // 现在要把儿子 v 合并到 u 上
        //
        // 合并前：
        // dp[u][j] = 已处理过的若干儿子里，选 j 个用户的最优收益
        // dp[v][t] = 在 v 子树里，选 t 个用户的最优收益
        //
        // 合并后：
        // 如果原来选了 j 个，现在再从 v 子树选 t 个，
        // 那总人数就是 j + t
        //
        // 所以新状态尝试更新 dp[u][j+t]

        // 为什么 j 要倒序？
        // 因为这是背包合并，倒序可以避免“同一个儿子被重复使用”
        for (int j = sz[u]; j >= 0; j--) {
            // t 从 1 开始，而不是 0 开始
            // 因为 t=0 表示这个儿子一个用户都不选
            // 那么 dp[u][j] 保持原样即可，不需要专门转移
            for (int t = 1; t <= sz[v]; t++) {
                // 只有当从 v 子树里选了至少 1 个用户，
                // 才需要开通边 u->v，因此要减去这条边费用 cost
                dp[u][j + t] = max(
                    dp[u][j + t],
                    dp[u][j] + dp[v][t] - cost
                );
            }
        }

        // 合并完 v 之后，u 子树里可选的总用户数要加上 v 子树里的用户数
        sz[u] += sz[v];
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> M;

    // 前 N-M 个点是中转站（包括根）
    for (int u = 1; u <= N - M; u++) {
        int K;
        cin >> K;
        while (K--) {
            int v, c;
            cin >> v >> c;
            g[u].push_back({v, c});
        }
    }

    // 最后 M 个点是用户，读它们的付款
    for (int u = N - M + 1; u <= N; u++) {
        cin >> pay[u];
    }

    dfs(1);

    // 从大到小找最大的 k，使得净收益 >= 0
    // 即：不亏本的前提下，最多能服务多少用户
    for (int k = M; k >= 0; k--) {
        if (dp[1][k] >= 0) {
            cout << k << '\n';
            break;
        }
    }

    return 0;
}
```
