# 01背包

## 场景
有 n 个物品，每个物品有：
- cost[i]：花费（重量）
- val[i]：价值

你有一个容量为 m 的背包。

**目标：** : 选一些物品，使得 总 cost ≤ m，同时 总价值最大。

## 思路
1. 按照任意顺序dp每一件物品

2. dp按照[cost, m]倒序遍历

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    vector<int> dp(m + 1, 0);

    for (int i = 1; i <= n; i++) {
        int cost, val;
        cin >> cost >> val;

        for (int j = m; j >= cost; j--) {
            dp[j] = max(dp[j], dp[j - cost] + val);
        }
    }

    cout << dp[m] << "\n";
}
```
