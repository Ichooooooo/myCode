# 基础/多源BFS

## 基础版

### 场景
一个源点, 求**无向图**中到别的点的最短路径

### 总体思路
- 初始化：dist[s]=0; q.push(s);
- 扩展：弹出 u，尝试更新邻居 v。
- 用队列+dist按层推进

### 基础代码
```cpp
vector<int> dist(n + 1, -1), parent(n + 1, -1);
    queue<int> q;

    dist[s] = 0;
    q.push(s);

    while (!q.empty()) {

        for (int v : g[u]) {
            if (dist[v] != -1) continue;          // 已访问
            dist[v] = dist[u] + 1;                // 层数 + 1
            parent[v] = u;                        // 记录路径
            q.push(v);
        }
    }
```

## 多源版

### 基本场景
多个固定源点到其他点的最短距离

### 基本思路
- 最开始将多个源点一起入队, dist = 0, 正常bfs

- 之后一次 BFS 跑完，dist[x] = 到最近源点的距离。

### 基础代码
```cpp
 // 若需要平局按最小编号源点：排序后入队
    sort(sources.begin(), sources.end());

    vector<int> dist(n + 1, -1), bel(n + 1, -1);
    queue<int> q;

    for (int s : sources) {
        if (dist[s] != -1) continue;  // 防重复源
        dist[s] = 0;
        bel[s] = s;
        q.push(s);
    }

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            bel[v] = bel[u];          // 继承所属源点, 如果需要源点的信息的话
            q.push(v);
        }
    }
```

#### 实现细节

1. 为什么可以共用一个dist
- 初始：源点 s 入队，dist[s]=0。

- 不变式：当你从队头弹出 u 时，队列里所有点的 dist 都 ≥ dist[u]。

- - 原因很直观：

- 只有当某个点 x 被弹出时，才会把它的未访问邻居 v 入队，并且赋值 dist[v]=dist[x]+1。

- 也就是说，新入队的点的距离永远是“当前弹出的这一层 + 1”。

- 队列 FIFO：先入队的（更小 dist 的层）一定先出队，所以队列会按层（0 层、1 层、2 层…）推进。

## 动态多源

### 场景
最开始源点不固定, 求到其他点的最短距离

### 思路
- 维护一个全局 dist[x] = 到当前已加入源点集合的最短距离

- 每次新增一批源点，只需要把这些新源点入队（把它们的 dist 强行改成 0），然后像 BFS 一样“松弛传播”，直到没有更优更新。

### 代码
```cpp
    // 按度数分桶
    for (int i = 1; i <= n; i++) {
        s.insert(du[i]);
        E[du[i]].push_back(i);
    }

    // 核心：按度数从大到小处理
    for (int dd : s) {
        queue<int> q;

        //  (1)   先回答本组：此时 dis 表示到“度数 > dd 的集合”的最短路, 因为实现的时候从deg大的递归到小的
        //     若之前遍历的时候没有更新, 则答案 -1
        for (int u : E[dd]) {
            ans[u] = (dis[u] >= INF ? -1 : dis[u]);

            // (2) 再把本组加入源点集合：把 dis[u] 变成 0, 变成新的源点
            //     并入队，作为多源 BFS 的新源点
            if (dis[u] > 0) {            // 保险写法（理论上此时不会已有0）, 去掉判断也可
                dis[u] = 0;
                q.push(u);
            }
        }

        // (3) 多源 BFS 松弛：把“到度数 >= dd 的集合”的距离传播出去
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : e[u]) {
                if (dis[v] > dis[u] + 1) {      //松弛,说明这时候找到了到达v的更短路径, 更新并push
                    dis[v] = dis[u] + 1;
                    q.push(v);
                }
            }
        }
    }
```

#### 思路

#### 代码
```cpp
void ovo(){   
    int n, m;  cin >> n >> m;

    vector <vector <int>> g (n + 5);
    vector <int> deg (n + 1);

    int u, v;
    for (int i = 0; i < m; i ++) {
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
        deg[u] ++;  deg[v] ++;
    }

    set <int, greater <int>> st;
    unordered_map <int, vector <int>> mp;
    for (int i = 1; i <= n; i ++) {
        st.insert(deg[i]);
        mp[deg[i]].push_back(i);
    }

    vector <int> ans (n + 1, -1), dist(n + 1, LLONG_MAX);
    queue <int> qu;

    for (auto k : st) {

        for (auto u : mp[k]) {  
            ans[u] = (dist[u] == LLONG_MAX ? -1 : dist[u]); //到这里, 前面deg更大的就已经遍历完了,此时更新ans
            dist[u] = 0;
            qu.push(u);
        }

        //以这一deg为源头bfs
        while (!qu.empty()) {
            int u = qu.front();  qu.pop();
            
            for (auto v : g[u]) {
                if (dist[v] > dist[u] + 1) {  //松弛
                    dist[v] = dist[u] + 1;
                    qu.push(v);
                }
            }
        }
    }

    for (int i = 1; i <= n; i ++) cout << ans[i] << " \n"[i == n];
}
```
