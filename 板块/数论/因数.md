# 因数分解

## 试除法

**关键点** : 对$1$单独判断(不进入循环)

```cpp
// O(sqrt(n)) 试除判断质数（n <= 1 不是质数）
bool isPrime_ll(long long n) {             
    if (n <= 1) return false;
    if (n % 2 == 0) return n == 2;
    for (long long i = 3; i <= n / i; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}
```
## 质因数分解

**关键点** : 一个数 $n$ 最多只会有一个大于根号 $n$ 的“大”因子

```cpp
//优化到O(log n)左右
    vector <PII> fac;
    if (x <= 1) return fac;

    int cnt = 0;
    while (x % 2 == 0) {
        x /= 2;
        cnt++;
    }
    if (cnt) fac.push_back({2, cnt});

    for (long long i = 3; i <= x / i; i += 2) {
            if (x % i == 0) {
                int c = 0;
                while (x % i == 0) {
                    x /= i;
                    c++;
                }
                fac.push_back({i, c});
            }
        }
    if (x > 1) fac.push_back({x, 1}); // 剩下的大质因子
```

### 为什么看起来两重循环却不是 $n^2$？

核心循环（忽略常数）：

- 外层枚举 $x$（只枚举在集合里的数）
- 内层枚举 $i = 2, 3, \dots, \left\lfloor \frac{n}{x} \right\rfloor$

因此当外层固定为某个 $x$ 时，内层循环次数约为 $\left\lfloor \frac{n}{x} \right\rfloor - 1$。

所以总迭代次数是：

$$
T=\sum_{x\in S}\left(\left\lfloor\frac{n}{x}\right\rfloor-1\right)
=O\left(\sum_{x\in S}\left\lfloor\frac{n}{x}\right\rfloor\right)
$$

最坏情况 $S=\{1,2,\dots,n\}$ 时：

$$
T \le \sum_{x=1}^{n}\frac{n}{x}
= n\sum_{x=1}^{n}\frac{1}{x}
= nH_n
$$

其中调和数

$$
H_n = 1+\frac{1}{2}+\cdots+\frac{1}{n} = O(\log n)
$$

因此：

$$
T = O(n\log n)
$$
