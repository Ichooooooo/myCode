# 错排/错配数

## 基本场景
**错配数（Derangement）**就是“一个排列里没有任何元素留在原位”的方案数，通常记作 Dn, 这种排列叫做错排

**前几个数字:** 0, 1, 2, 9, 44, 265....

## 公式推理

考虑数字1放在那里, 最初有$n - 1$中方案, 考虑放在了位置 $k$, 那么接下来两种情况

1. 数字$k$ 放在了 位置1
问题转化为 $n - 2$的错排, 即$D_{n - 2}$

2. 数字$k$ 放在了 其他位置
问题转化为 $n - 1$的错排, 此时因为确定 $k$ 不会放在位置 $1$, 所以 $k$ 相当于位置1的数字, 即$D_{n - 1}$

因为最初$k$有$n - 1$种可能性, 所以最终有$ D_n = (n - 1)(D_{n - 1} + D_{n - 2})$

## 最终公式(递推版)

$$ D_n = (n - 1)(D_{n - 1} + D_{n - 2})$$

注意$D_0$

## 代码实现

```cpp
void init () {
    f[1] = 0, f[2] = 1;
    for (int i = 3; i < N; i ++) {
        f[i] = (i - 1) * (f[i - 1] + f[i - 2]) % mod;
    }
}
```
## 与环分解的关系
“没有元素在原位”等价于：排列里 没有长度为 1 的环

所以错排本质上就是：对 n 个元素做排列

并且这个排列的环分解中不允许出现自环
