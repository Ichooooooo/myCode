## 基础板子

```cpp
const int N = 1e5;
int f[N], g[N]; // 数组的大小由N决定, 这里一般不用动, 特殊情况越界则扩容

int qpow (int a, int b)
{
    int res = 1;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

int C (int n, int m)
{
    if (m < 0 || m > n) return 0;

    return f[n] * g[m] % mod * g[n - m] % mod;
}

int main ()
{
    ios::sync_with_stdio(0);
    cin.tie(0);
    int _ = 1;
    // cin >> _;

    f[0] = 1, g[0] = 1;
    // 这里N循环到哪里由具体的题目定!!总是注意边界取等还是不取, 最好的办法是总是取大一点
    for (int i = 1; i <= N; i++) {
        f[i] = f[i - 1] * i % mod;  //f是普通排列
        g[i] = qpow(f[i], mod - 2) % mod;   //g为逆元位
    }

    while (_--) {
        solve();
    }
    return 0;
}   
```
## 挡板法

挡板法用于计数：把“若干个相同的球/单位”分配到“若干个盒子/段”里，或等价地计数满足某些**非负/正整数解**的方程组数量。核心是把解映射到“星星 + 挡板”的排列。

---

### 0. 基本形式与记号

- 设有 `k` 个变量（盒子），总和为 `n`（星星数量）。
- 常见两类：
  1) **允许空（非负整数）**：`x1 + x2 + ... + xk = n`, `xi >= 0`
  2) **不允许空（正整数）**：`x1 + x2 + ... + xk = n`, `xi >= 1`

---

### 1) 允许空：非负整数解

#### 结论
`x1 + x2 + ... + xk = n, xi >= 0` 的解数为：

\[
\binom{n + k - 1}{k - 1}
\]

#### 理解）
将n个元素分配给k个不同的盒子，每个盒子至少分配一个，因为n个元素之间共有n-1个空，在这n个元素之间只需要插入k-1个板子就可以将这n个元素分成k份，且每一份至少有一个，故一共有$\binom{n  - 1}{k - 1}$

**允许空**: 引入虚拟元素：为了处理允许空的情况，我们可以为每个容器预先添加一个“虚拟”的元素（例如，虚拟的小球）。这样，即使某个容器在最终分配中没有实际的小球，也会因为虚拟小球的存在而被视为非空

故

\[
\binom{n + k - 1}{k - 1}
\]

---

### 2) 不允许空：正整数解

#### 结论
`x1 + x2 + ... + xk = n, xi >= 1` 的解数为：

\[
\binom{n - 1}{k - 1}
\]
（前提 `n >= k`，否则为 0）

---

### 3) [应用场景](https://www.nowcoder.com/practice/e91f8e9c0b1f4df69d5d0814e173266c?channelPut=tracker2)

#### 单调序列计数（非常常用）
**非降序列** `b1 <= b2 <= ... <= bL` 且 `bi` 在某个值域区间里：
- 设取值范围大小为 `m`（例如 `[1..m]`）
- 非降长度 `L` 的序列数量为：

\[
\binom{L + m - 1}{m - 1}
\]

解释：等价于把 `L` 个位置分配到 `m` 个值上，令 `xi` 表示值 `i` 出现次数，`xi>=0` 且总和为 `L`。

同理，**非增序列**可通过翻转/变换成非降来套公式。
