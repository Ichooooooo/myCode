# 二分图染色

## 基础
- 给每个点染成 0/1 两种颜色，要求每条边两端颜色不同
- 一个图是二分图，当且仅当它没有奇环

## 应用
1. 判断是否存在奇环
2. 每个连通块两侧取 max/min, 一般会被分为两侧
3. 处理“相反关系
4. 奇偶距离模型, 同色点之间路径长度为偶数, 异色点之间路径长度为奇数
5. 网格图常用棋盘染色

## 题目
- (处理矛盾)[https://codeforces.com/problemset/problem/1702/E]
- (单向边依旧双向验证)[https://codeforces.com/contest/1594/problem/D]

## 代码
```cpp
vector<vector<int>> g(n + 1);
vector<int> color(n + 1, -1);

bool ok = true;

// 因为图不一定是全部连通的, 可能需要多个起点
for (int s = 1; s <= n; s++) {
    if (color[s] != -1) continue;

    queue<int> q;
    color[s] = 0;
    q.push(s);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (color[v] == -1) {
                color[v] = color[u] ^ 1;
                q.push(v);
            } else {
                // 这里处理冲突情况
                if (color[v] == color[u]) {
                    ok = false;
                }
            }
        }
    }
}
```
