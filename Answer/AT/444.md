### E

#### 知识点
处理时间复杂度+边界判断减少时间复杂度+有序对set

#### 思路

1. 首先, 可以想到让题目变得有序而且时间复杂度满足, 数据量1e5想到固定左端点遍历试试

2. 发现这种情况下的ans变得很好算在 要求包含左l的情况下

3. 然后从小处入手, 想该怎么寻找满足条件的最大右区间

4. 动态考虑, 每次扩展右边区间的时候, 实际上要判断已有区间加入新元素之后能否满足, 也就是只用判断新元素是否满足

5. 可以贪心想到实际上只用考虑最小的大于a[r]的数, 和最大的小于a[r]的数(即距离a[r]最近的两个数字是否满足)

6. 那么需要维护一个有序数组, 才能二分查找, 并且要可以插入删除, 我们使用set

7. 然后也是动态考虑, 发现实际上, 扩展左区间和扩展右区间过程差不多, 用一个set维护, 每次扩展左区间的时候先删除原来的就好

##### 时间复杂度近似O(nlogn)

#### 代码
```cpp
void ovo(){   
    int n, m;  cin >> n >> m;
    vector <int> a (n);
    
    for (int & i : a) cin >> i;
    
    int ans = 0, r = 0;
    set <int> st;
    st.insert(-1e9); st.insert(2e9);  // 细节1 : 注意为了让二分查找结果总是合理(能找到)且满足条件, 插入一定满足的两个数
    for (int l = 0; l < n; l ++) {
        while (r < n) {
            auto it = st.lower_bound(a[r]); 
            if (*it - a[r] < m) break;  // 细节2 : 这里因为要计算, 所以最开始插入的时候不可以LLMAX, 以后都别用了
            it --;
            if (a[r] - *it < m) break;
            st.insert(a[r]);
            r ++;
            
        }
        ans += (r - l);
        st.erase(a[l]);
    }
    cout << ans << "\n"; // '\n'
}
```
