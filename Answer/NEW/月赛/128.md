### A

#### 知识点 : 你是个🐷

#### 总结 :
1. 你的代码真的很慢debug, 思路想清楚用简洁的代码表示好吗

2. 位运算常见坑 :
- 优先级, 基本上最低级, 每次使用都加括号
- 移位越界, 每次写1ULL << bit就好
- 掩码构造, 注意(1ULL << 64)不可以, 超过ULL范围了, 用~0ULL

3. 位运算常见使用:
```cpp
x |= (1ULL << k) //置位
x &= (~ (1ULL << k)) // 清位
x ^= (1ULL << k) // 翻转
```
4. ~的常见使用: 把所有二进制位取反
- ~0ULL // 64 位全 1
- ~0u // 32 位全 1

4. 注意题目中关键词, 有"哪些地方我可能看错的"意识, 比如本题的O和o
