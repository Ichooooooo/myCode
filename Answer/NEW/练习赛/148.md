## 具体情况

### B

#### 基本考点
暴力枚举, dfs或者位运算枚举

#### 总结

1. 写题需要脚踏实地, 围绕题目, 看要求, 看公式, 看数据量, 结合数据量解题非常重要

2. dfs存储信息
- 本题是用dfs枚举, 存储最终所需要的信息可以直接用全局数组, 每次递归之前修改状态就保证上次的结果不会影响到这次, 对应本题的vis

3. dfs回溯用法
- 撤销现场（状态恢复）
做排列/棋盘/组合时，你会维护 path / used / cnt 等状态：

下去前：做选择、修改状态

回来后：撤销修改（这步就叫回溯的“撤销现场”）

只有这样才能正确尝试下一种选择

- 汇总信息（后序返回）
树 DP/递归统计时，往往在回来的时候做：

ans[u] = merge(ans[v])

或者根据子结果更新全局最优

这里“回溯”更像“后序处理”。

4. 位运算枚举/不精确版
``` cpp
    // 每个编码s是一个n位二进制数，范围从0到2^n - 1
    for (int s = 0; s < (1 << n); ++s) {
        vector<int> subset;  // 当前子集

        for (int i = 0; i < n; ++i) {
            if (s >> i & 1) {
                subset.push_back(a[i]);
            }
        }
    }
```
注意事项
- 位运算范围是$s < (1 << n)$
- 两个地方的变量总是出错 1. 局部修改全局, 导致后面出错 2. 局部变量全局声明, 缺少独立性
