#### 总结

1. 打表的时候如果输出某两个参数没有明显规律，就切换参数，灵活处理

2. 异或结论

- (x - y) <= (x ^ y) <= (x + y)

-  那么首先可知$min(x \oplus y) = (x - y)$, 接下来让$(x - y)$越小越好, 然后又$x != y$, 则$min (x - y) = n$

- 然后开始构造x和y,让其满足$ x \oplus y == n$, 根据二进制观察, 直接讲x想左移动bit位i空出一个n的位置, y = x + n即可

- 为什么满足x, y是n的倍数, 因为左移实际上就是乘上(2 ^ bit)
